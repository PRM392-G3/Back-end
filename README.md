# 🌐 Nexora – Social Network Backend for Mobile  
### **A Modern, Intelligent, and Scalable API for the Next-Gen Mobile Social Experience**  
### **Hệ thống mạng xã hội di động thông minh – hiện đại, bảo mật và linh hoạt**

---

## ⚙️ Overview / Tổng Quan

**Nexora** is the backend infrastructure powering a new-generation **mobile social network**, built on **ASP.NET Core** with modern cloud and AI integration.  
It delivers real-time chat, AI-driven content interaction, and a seamless authentication experience — all packaged in a secure, containerized environment.

**Nexora** là **hệ thống Back End mạng xã hội di động thế hệ mới**, được phát triển bằng **ASP.NET Core**, tích hợp **trí tuệ nhân tạo**, **giao tiếp thời gian thực**, và **xác thực bảo mật hiện đại**.  
Dự án được thiết kế hướng tới **hiệu năng, độ tin cậy**, và **trải nghiệm người dùng mượt mà trên di động**.

---

## 🧠 Core Technologies / Công Nghệ Chính

| Technology / Công Nghệ | Description / Mô Tả |
|-------------------------|----------------------|
| **ASP.NET Core API** | Core framework providing RESTful APIs, dependency injection, middleware, and security handling.<br>→ Nền tảng chính xây dựng API RESTful với kiến trúc middleware mạnh mẽ và bảo mật cao. |
| **PostgreSQL (Supabase)** | Cloud-hosted relational database for structured data and analytics.<br>→ CSDL quan hệ trên Supabase, lưu trữ dữ liệu người dùng, bài viết, nhóm và tin nhắn. |
| **Google Firebase OAuth2** | Authentication using Google accounts via OAuth2 standard.<br>→ Xác thực đăng nhập bằng tài khoản Google, an toàn và tiện lợi. |
| **JWT (JSON Web Token)** | Token-based authentication ensuring stateless API requests.<br>→ Xác thực bảo mật bằng JWT, giúp API mở rộng dễ dàng và không cần lưu session. |
| **SignalR** | Real-time WebSocket communication for instant messaging and presence tracking.<br>→ Giao tiếp thời gian thực cho chat, hiển thị trạng thái hoạt động và thông báo trực tiếp. |
| **Firebase Cloud Messaging (FCM)** | Mobile push notification service for user engagement.<br>→ Gửi thông báo đẩy đến thiết bị di động khi có tin nhắn hoặc hoạt động mới. |
| **Supabase Storage** | Secure file and media storage with CDN delivery.<br>→ Lưu trữ hình ảnh, video, và file bài viết trên đám mây Supabase. |
| **OpenAI API (GPT Integration)** | AI-powered content generation, smart suggestions, and text analysis.<br>→ Tích hợp trí tuệ nhân tạo GPT của OpenAI để gợi ý nội dung, phân tích bình luận, hoặc trò chuyện thông minh. |
| **Docker** | Containerized deployment for cross-platform consistency.<br>→ Đóng gói ứng dụng trong container giúp triển khai dễ dàng và đồng nhất. |
| **Linux Deployment** | Production deployment optimized for Linux servers.<br>→ Môi trường triển khai tối ưu trên máy chủ Linux (ổn định, hiệu năng cao). |
| **Ngrok** | Secure tunnel for local API testing and SignalR development.<br>→ Tạo đường dẫn HTTPS tạm thời để test API và kết nối realtime trong quá trình dev. |
| **Custom Domain** | Public domain for external API access.<br>→ Tích hợp tên miền riêng giúp hệ thống chuyên nghiệp hơn. |
